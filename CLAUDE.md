# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev       # start dev server at localhost:4321
npm run build     # build for production
npm run preview   # preview production build locally
```

Sanity Studio is embedded at `/admin`. For local dev, add `http://localhost:4321` as a CORS origin in the Sanity project dashboard.

## Architecture

**Astro (SSR) + Sanity CMS + Vercel**

- `output: 'server'` with `@astrojs/vercel` adapter — all pages are server-rendered, no static generation
- Sanity is the only active content source. The original `src/content/blog/` markdown collection is unused
- Tailwind via `@tailwindcss/vite` plugin (not the Astro integration)

**Sanity integration:**
- Project ID: `7oxpyma4`, dataset: `production`
- `astro.config.mjs` — configures `@sanity/astro`, embeds Studio at `/admin`
- `sanity.config.ts` — Studio config, registers schemas via `structureTool` from `sanity/structure`
- `src/schemas/post.ts` — the only document type: `title`, `slug`, `publishedAt`, `body` (raw HTML string), `imageUrl` (URL)

**Fetching content:**
```ts
import { sanityClient } from 'sanity:client'; // virtual module, not a package import
const posts = await sanityClient.fetch(`*[_type == "post"] | order(publishedAt desc) { title, slug, publishedAt, body, imageUrl }`);
```
Use GROQ. Test queries in Sanity Studio Vision tool at `/admin`.

**`body` field is raw HTML** — rendered with `set:html={post.body}` in `[slug].astro`. The LLM autoblogger writes and stores HTML directly; there is no portable text or markdown conversion.

**Page structure:**
- `src/pages/index.astro` — homepage with integrated hero nav (no separate Header component), sticky wave-bottom hero, category strip, blog sections, stats pulled live from Sanity (`posts.length`, posts this year, days since newest post)
- `src/pages/blog/index.astro` — all posts grid
- `src/pages/blog/[slug].astro` — SSR dynamic post page, fetches by `Astro.params.slug`
- `src/pages/about.astro` — uses `Header` component
- `src/components/Header.astro` — used on all non-homepage pages, dark background with yellow logo accent
- `src/components/Footer.astro` — shared footer
- `src/components/BaseHead.astro` — handles all meta/OG tags; accepts `image?: string` for OG image override; defaults to `/hero.jpg`

**Color palette** (defined in `src/styles/global.css`):
- `--primary` / `--primary-dark` / `--primary-light` — turquoise (`#00B4A6`)
- `--orange` / `--orange-dark` / `--orange-light` — golden yellow (`#E8A820`), used for all CTAs
- `--yellow` — sunny yellow (`#FFD166`), used for logo accent and hero highlights
- `--dark` — deep ocean (`#0D2830`), used for hero and header backgrounds

**Static assets:**
- `/public/hero.jpg` — hardcoded hero image for the homepage and default OG image
- `/public/favicon.svg` and `/public/favicon.ico`

**Content pipeline (external, not in this repo):**
- n8n autoblogger publishes posts to Sanity via the Mutations API
- Post `body` is raw HTML generated by an LLM
- Post `imageUrl` is an external URL (hotlinking from external sites will be blocked by those sites' WAF/hotlink protection)

**OG / social sharing:**
- Default OG image is `/hero.jpg` (served from `public/`)
- Blog posts can override with `image={post.imageUrl}` passed to `<BaseHead>`

**`vercel.json`** — sets CSP headers to allow Vimeo and YouTube iframes in blog post bodies.
